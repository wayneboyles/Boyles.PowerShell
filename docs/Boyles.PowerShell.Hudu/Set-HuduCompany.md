# Set-HuduCompany

## SYNOPSIS
Updates an existing company in the connected Hudu instance.

## SYNTAX

```
Set-HuduCompany [-Id] <Int32> [[-Name] <String>] [[-Nickname] <String>] [[-CompanyType] <String>]
 [[-AddressLine1] <String>] [[-AddressLine2] <String>] [[-City] <String>] [[-State] <String>] [[-Zip] <String>]
 [[-CountryName] <String>] [[-PhoneNumber] <String>] [[-FaxNumber] <String>] [[-Website] <String>]
 [[-IdNumber] <String>] [[-ParentCompanyId] <Int32>] [[-Notes] <String>]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Updates the company with the given ID via the connected HuduClient (see Connect-Hudu).
Only
the parameters actually supplied are sent in the request body, so omitted properties are left
unchanged.
Returns $null instead of throwing when the ID doesn't exist, since Hudu responds
with an HTTP 404 in that case.
Supports -WhatIf/-Confirm.

## EXAMPLES

### EXAMPLE 1
```
Set-HuduCompany -Id 5 -Website 'https://new-acme.example.com'
```

Updates company 5's website, leaving its other properties unchanged.

### EXAMPLE 2
```
Get-HuduCompany -State 'TX' | Set-HuduCompany -CountryName 'United States'
```

Sets the country on every company located in Texas.
